## What is this

yoke gives any MCP client access to the Chrome profile you already use, including your signed in sessions, cookies, and extensions. It can inspect every tab, read pages, follow links, type, take screenshots, and watch console and network activity. It runs locally through an unpacked Chrome extension and a native messaging host, and asks for broad browser permissions.
